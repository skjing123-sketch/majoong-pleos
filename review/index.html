확인 범위

  • 저장소에는 실제 분실동물 조회 API와 사진 중계 코드가 구현돼 있습니다.
  • 실시간 조회에는 인증키를 설정한 로컬 백엔드가 필요합니다. 이 페이지는 조회 시각을 기록한 자료를 읽습니다.
  • 내비 전체 화면 위 사진 팝업은 제안 UI이며 아직 구현되지 않았습니다. 현재 사진 안내는 마중 앱 영역이나 분할 화면 안에서 표시합니다.
  • 배치 시안은 실제 SDK 도착·P단 주차·사진 팝업의 통합 실행 증거가 아닙니다.
  • API가 발견 완료 상태를 제공하지 않아 현재도 찾는 중인지 확정할 수 없습니다.
