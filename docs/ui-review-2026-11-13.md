# UI 정리와 남은 시각 점검

생성 이미지 로고를 코드 기반의 파랑/흰색 발바닥·집 벡터로 바꾸고 Android launcher와 연결 gate에도 같은 도형·팔레트를 적용했다. 웹은 중복 스타일 대신 단일CSS로 정리했다. 흰색 header·중립 배경·선명한 글자·공고사진을 중심으로 구성하며, 좁은 pane은 작은사진과본문이 나란한목록이다. 하단넛지는48px사진과한줄제목·48px터치영역을 사용한다.

정적검사: 기존DOM ID누락0, SVG참조오류0, 현재진입점과넛지의생성로고참조0. 기본버튼명암비4.71:1, 본문5.59:1, 보조글자4.68:1. reduced-motion설정을존중한다.

화면제어도구로IAB새탭과Chrome접속을 시도했지만각각시간초과·server timeout오류로실제새UI를관측하지못했다. 사용중인브라우저를다른기술로대신조작하지않았다. 별도headless테스트브라우저를 포함한 화면점검은 사용자 요청으로 보류했다. 따라서1280×720·540px분할·390px화면의최종렌더링,설정/상세/6초넛지클릭검사는아직확인한것으로표기하지않는다.

공식참조: [Pleos UI가이드](https://document.pleos.ai/docs/connect/guide/docs-design/Introduction/intro), [Typography](https://document.pleos.ai/en/docs/connect/guide/docs-design/foundations/typography). 실제차량에서의글자물리크기·원거리읽기·주야간밝기측정은미완료다. 현재UI는light모드이며시스템야간모드자동전환은미구현이다.
